Clementine Remote is a remote control for Clementine, a free music player for macOS, Windows and Linux. It needs Clementine running on a computer on the same network as the device.

To test it:
1. Install Clementine 1.3 or later from https://www.clementine-player.org/ and add some music to its library.
2. In Clementine, open Tools → Preferences → Network Remote and turn on "Use a network remote control". To test downloads, also allow downloads there.
3. Open Clementine Remote on a device on the same Wi-Fi network, allow it to find devices on the local network, and connect: it finds Clementine by itself, or enter the computer's address shown in Clementine's Network Remote preferences.

The app has no accounts and collects no data.
